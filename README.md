# Hikaru's Blog

这是我的个人博客，使用 Jekyll 和 GitHub Pages 搭建。

## 访问博客

访问地址：https://Hikaru-1216.github.io

## 本地开发

如果您想在本地开发，请按照以下步骤：

1. 安装 Ruby 和 Jekyll
2. 克隆此仓库
3. 运行 `bundle install`
4. 运行 `bundle exec jekyll serve`
5. 在浏览器中打开 http://localhost:4000

## 如何添加文章

在 `_posts` 文件夹中创建新的 Markdown 文件，命名格式为 `YYYY-MM-DD-标题.md`。
